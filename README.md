# Atividade Aula 10 – Desafio CSS TechNews Today

## Sobre a atividade

Nesta atividade, desenvolvi uma página web para o portal TechNews Today, com o objetivo de praticar a utilização de HTML e CSS na criação de um site de notícias sobre tecnologia.

## Desenvolvimento

A página foi organizada em algumas seções principais:

- **Cabeçalho:** apresenta o nome do portal e uma breve descrição, com cores em degradê e efeito de transparência.
- **Artigo em destaque:** apresenta uma notícia sobre inteligência artificial, com data, resumo e opção para expandir o texto.
- **Seção de vídeo:** contém um vídeo do YouTube relacionado à tecnologia.
- **Newsletter:** possui um formulário com campo de e-mail, seleção de área de interesse, confirmação dos termos e botão de inscrição.
- **Rodapé:** apresenta os direitos reservados e um endereço de e-mail para contato.

## Recursos utilizados

No CSS, utilizei degradês, sombras, bordas arredondadas, efeitos ao passar o mouse e transparência com `backdrop-filter`. Também organizei os elementos com CSS Grid e adicionei uma media query para adaptar o layout a telas menores, como as de celulares. O cabeçalho utiliza `position: sticky` para permanecer visível durante a rolagem da página.

## Arquivos do projeto

- `desafio10a.html`: contém a estrutura e o conteúdo da página.
- `10a_desafio.css`: contém os estilos e a parte visual do site.

## Conclusão

Com esta atividade, pratiquei recursos de CSS para melhorar a aparência e a organização de uma página web, além de trabalhar a adaptação do layout para diferentes tamanhos de tela.
